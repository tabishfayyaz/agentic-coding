### Mental Mode:
- Context = **RAM**
- `.opencode/plan` = hard drive

You don't keep everything in RAM.

### A Useful Diagnostic

```
"I need another perspective/context for this."
            → AGENT

"I've explained this procedure before."
            → SKILL

"I've typed this workflow before."
            → COMMAND

"I keep manually retrieving/running this."
            → TOOL/MCP
```

### MCP
- `opencode mcp list` → list current configured MCP servers
- `opencode mcp auth Figma` → start authentication flow for Figma MCP
  
### Context Thresholds:
- 0-50% → safe
- 50-60% → be cautious
- 60-70% → wrap up session
- 70%+ → reset

### What counts towards context:
- large slice text
- feature descriptions
- pasted code
- previous conversation history
- repeated prompts
